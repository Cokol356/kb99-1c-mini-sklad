# kb99-1c-mini-sklad

Учебная конфигурация «Мини-Склад» на платформе 1С:Предприятие 8.3.

## Что внутри
- Справочники: Товары, Контрагенты
- Документы: Поступление, Реализация (движения по регистру накопления ОстаткиТоваров)
- Подсистема «Мини-Склад»
- Выгрузка конфигурации - папка `src`

## Как открыть
1. Создайте пустую информационную базу в 1С.
2. Откройте Конфигуратор → Конфигурация → Загрузить конфигурацию из файлов.
3. Укажите папку `src`.
4. Нажмите F5 и подтвердите обновление конфигурации БД.
